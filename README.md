# AmneziaVPN to Sing-Box Converter

A lightweight browser-based tool to convert AmneziaWG configurations (`vpn://` keys or native AmneziaWG format) into AWG-compatible endpoint configs for [sing-box with AWG support](https://github.com/spoofi/sing-box-awg).

## Try now

<https://spoofi.github.io/amnezia-to-sing-box/>

## ✨ Features

- 🔐 **Client-side only**: All processing happens locally in your browser — no data leaves your device.
- 🔄 **Editable output**: Tweak JSON fields (tag, name, params) before copying.
- 🎨 **Simple UI**: Paste → Convert → Copy.

## 🚀 Usage

1. Paste your `vpn://` key or AmneziaWG config.
2. Click **Convert**.
3. Edit the result if needed, then **Copy** to use in your `sing-box` config.

## ⚙️ Requirements

- A [sing-box fork with AWG support](https://github.com/spoofi/sing-box-awg) (required to use the generated configs).

## 🛡️ Privacy

No telemetry, no backend, no tracking. Your configs never leave your browser.
